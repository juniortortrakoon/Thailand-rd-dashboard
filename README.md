# Thailand R&D Intelligence Dashboard

Vite + React dashboard comparing Thailand's R&D expenditure and personnel
against BRICS, higher-tier, and ASEAN peer groups (IMD World Competitiveness
Yearbook data, 1995–2024).

## Run locally
```
npm install
npm run dev
```

## Build for production (e.g. Vercel)
```
npm run build
```

All dashboard markup, styling, data, and chart logic live in `src/App.jsx`.
